Neon Vice Cover Studio turns your photos into a GTA-style multi-panel poster cover: upload up to three photos, pick one of four layouts (Sunset Grid, Triptych, Split Hero, Quad), crop and position each panel by dragging, write a bold caption, pick a sunset or neon grade, and export a PNG in 1080 × 1080, 1080 × 1350 or 1920 × 1080. It runs entirely offline in a desktop browser — photos stay on your machine. Original design: no Rockstar logo, artwork, character or font; the display font is Archivo Black under the SIL Open Font License.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
